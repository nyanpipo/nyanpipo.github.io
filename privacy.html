プライバシーポリシー

制定日：2026年10月12日 ／ English version: below

にゃの時事報告（以下「当チャンネル」）は、動画の制作・投稿に使うツール「nya-jiji」（以下「本ツール」）とこのウェブサイトで扱う情報について、次のとおり取り扱います。

1. 本ツールが扱う情報

本ツールは、当チャンネルの運営者だけが使うツールです。運営者が自分のアカウントで許可した範囲で、次の情報を扱います。

  • YouTube（YouTube API サービス）：当チャンネルの YouTube チャンネルへの動画・サムネイルのアップロードと公開設定、当チャンネルの動画の情報と分析データ、当チャンネルの動画に付いたコメントの読み取り
  • TikTok：当チャンネルの TikTok アカウントへの動画の投稿、アカウントの基本情報と投稿した動画の情報の読み取り
  • 公開情報：官公庁・報道機関が公開している新着情報の見出しと URL、Google トレンド・YouTube・X の急上昇ワード（話題の選定にだけ使い、急上昇ワードは長期間保存しません）

本ツールは、視聴者のアカウント情報、連絡先、位置情報などの個人情報を収集しません。コメントは、内容の確認と誤りの把握のためにだけ読み取り、第三者に提供しません。

2. 利用目的

上記の情報は、当チャンネルの動画の制作・投稿・運営の改善にだけ使います。広告配信や、第三者への販売・提供には使いません。

3. 保存と管理

本ツールが扱う情報は、運営者だけがアクセスできる非公開の環境に保存し、第三者には共有しません。各プラットフォームへの接続に使う認証情報は、暗号化された保管場所で管理します。YouTube API サービスから取得した情報の保存期間は次のとおりです。

  • 当チャンネルの分析データと統計（再生回数など）：運営の改善に必要な期間保存します。保存している間は、30日ごとに本ツールへの許可が有効であることと、動画が削除されていないことを確認します。
  • それ以外の当チャンネルのデータ（動画の情報やコメントなど）：取得から30日以内に削除するか、最新の内容に更新します。
  • 他のチャンネルの情報（急上昇の動画の情報など）：その処理の中でだけ使い、保存しません。

4. データの削除と許可の取り消し

  • 本ツールが保存したデータの削除は、下記のメールアドレスで依頼できます。依頼を受けてから7日以内に削除します。
  • 本ツールに許可したアクセスは、Google アカウントのセキュリティ設定 からいつでも取り消せます。取り消しを確認した場合は、YouTube API サービスから取得して保存していたデータを7日以内に削除します。
  • 本ツールが保存したデータを削除しても、YouTube 上の動画やデータは削除されません。YouTube 上のデータは YouTube（YouTube Studio など）で削除してください。

5. 第三者のサービス

本ツールは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。TikTok の利用には TikTok の利用規約とプライバシーポリシーが適用されます。本ツールは広告を配信せず、第三者にコンテンツを配信させることもありません。

6. このウェブサイト

このウェブサイトは GitHub Pages で公開しています。当チャンネルはアクセス解析や Cookie を使っておらず、閲覧者の端末に情報を保存したり、端末から情報を集めたりしません。ホスティング事業者が技術的なログを記録する場合があります。

7. お問い合わせ・変更

このポリシーに関するお問い合わせは、下記のメールアドレスまでご連絡ください。内容を変更する場合は、このページで告知します。

Privacy Policy (English)

Effective: October 12, 2026. If the Japanese and English versions differ, the Japanese version prevails.

1. Scope

This policy covers nya-jiji (the "Tool"), a private tool that the operator of the channel "Nya no Jiji Houkoku" uses only for the operator's own YouTube channel and TikTok account, and this website. The Tool uses YouTube API Services.

2. Information the Tool accesses

  • YouTube (YouTube API Services), within the scopes the operator authorized with the operator's own Google account: uploading videos and thumbnails to the channel and setting their visibility; reading information and analytics about the channel's own videos; reading comments on the channel's own videos.
  • TikTok: posting videos to the operator's own account and reading basic account and video information.
  • Public information: headlines and URLs published by government agencies and news organizations, and trending keywords from Google Trends, YouTube and X, used only to choose topics.

The Tool does not collect viewers' account information, contact details, location or other personal information. Comments are read only to check feedback and find errors, and are never shared.

3. Use and sharing

Information is used only to produce, publish and improve the channel's videos. It is not used for advertising and is not sold or shared with any third party. The Tool does not serve ads and does not allow third parties to serve content.

4. Storage and retention

  • Data is stored in a private environment that only the operator can access. Credentials are kept in an encrypted secret store.
  • Analytics data and statistics about the channel's own videos (such as view counts) are kept as long as needed to improve the channel. While stored, the Tool re-confirms at least every 30 days that its authorization is still valid and that the videos still exist.
  • Other YouTube API data about the channel (such as video metadata and comments) is deleted or refreshed within 30 days.
  • Information about other channels (such as trending videos) is used only during processing and is not stored.

5. Deletion and revoking access

  • You can request deletion of data stored by the Tool by emailing the address below. We delete it within 7 days.
  • In addition to that procedure, you can revoke the Tool's access to your data at any time via the Google security settings page: https://security.google.com/settings/security/permissions. When revocation is confirmed, data obtained from YouTube API Services is deleted within 7 days.
  • Deleting data stored by the Tool does not delete any data on YouTube. To delete data on YouTube, use YouTube (for example, YouTube Studio).

6. Third-party services

Use of YouTube is subject to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy (http://www.google.com/policies/privacy). Use of TikTok is subject to TikTok's terms and privacy policy.

7. This website and cookies

This website is hosted on GitHub Pages. We do not use analytics or cookies, and we do not store or collect information on or from visitors' devices. The hosting provider may keep technical logs.

8. Contact

Questions or complaints about these privacy practices: nya.jiji.info@gmail.com. Changes to this policy will be posted on this page.
