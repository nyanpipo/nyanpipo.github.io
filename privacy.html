プライバシーポリシー

制定日：2026年10月12日

にゃの時事報告（以下「当チャンネル」）は、動画の制作・投稿に使うツール「nya-jiji」（以下「本ツール」）とこのウェブサイトで扱う情報について、次のとおり取り扱います。

1. 本ツールが扱う情報

本ツールは、当チャンネルの運営者だけが使うツールです。運営者が自分のアカウントで許可した範囲で、次の情報を扱います。

  • YouTube（YouTube API サービス）：当チャンネルの YouTube チャンネルへの動画・サムネイルのアップロードと公開設定、当チャンネルの動画の情報と分析データ、当チャンネルの動画に付いたコメントの読み取り
  • TikTok：当チャンネルの TikTok アカウントへの動画の投稿、アカウントの基本情報と投稿した動画の情報の読み取り
  • 公開情報：官公庁・報道機関が公開している新着情報の見出しと URL、Google トレンド・YouTube・X の急上昇ワード（話題の選定にだけ使い、急上昇ワードは長期間保存しません）

本ツールは、視聴者のアカウント情報、連絡先、位置情報などの個人情報を収集しません。コメントは、内容の確認と誤りの把握のためにだけ読み取り、第三者に提供しません。

2. 利用目的

上記の情報は、当チャンネルの動画の制作・投稿・運営の改善にだけ使います。広告配信や、第三者への販売・提供には使いません。

3. 保存と管理

本ツールが扱う情報は、運営者だけがアクセスできる非公開の環境に保存します。各プラットフォームへの接続に使う認証情報は、暗号化された保管場所で管理します。各サービスの規約で保存期間が定められている情報は、その期間を超えて保存しません。

4. 第三者のサービス

本ツールは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。本ツールに許可したアクセスは、Google アカウントのセキュリティ設定 からいつでも取り消せます。TikTok の利用には TikTok の利用規約とプライバシーポリシーが適用されます。

5. このウェブサイト

このウェブサイトは GitHub Pages で公開しています。当チャンネルはアクセス解析や Cookie を使っていません。ホスティング事業者が技術的なログを記録する場合があります。

6. お問い合わせ・変更

このポリシーに関するお問い合わせは、下記のメールアドレスまでご連絡ください。内容を変更する場合は、このページで告知します。
